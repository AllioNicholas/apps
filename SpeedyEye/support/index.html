Frequently asked questions

My scores don't appear on the Game Center leaderboards

Make sure you're signed in to Game Center in the Settings app. Scores are submitted when you finish a game while signed in.

How do I turn off sounds?

Tap the sound button on the start screen. Haptics follow the system setting in Settings › Sounds & Haptics.

Can I start a game with Siri?

Yes. Say “Play Up Count in SpeedyEye”, or add the Start Game action in the Shortcuts app.
