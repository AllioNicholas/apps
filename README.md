# apps

Landing and support pages for my apps, served by GitHub Pages at https://allionicholas.github.io/apps/.

| App | Landing page | Support |
| --- | --- | --- |
| SpeedyEye | [/apps/SpeedyEye/](https://allionicholas.github.io/apps/SpeedyEye/) | [/apps/SpeedyEye/support/](https://allionicholas.github.io/apps/SpeedyEye/support/) |

To add an app, create a folder named after it (the folder name is the URL path, case-sensitive) with an `index.html`, and list it in the root `index.html`. Keep links relative (no leading `/`) so the pages work both under `/apps/` and on a custom domain.
